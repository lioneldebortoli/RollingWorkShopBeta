# Workshop Rolling Code — Landing Page

Landing page para la venta de entradas del workshop **¿Por dónde empiezo a programar?** de Rolling Code School.

## Tecnologías

- HTML5 semántico
- CSS3 con variables custom
- Bootstrap 5.3.3 (CDN)
- JavaScript vanilla (validación de formularios, interactividad del checkout)
- Google Fonts — Plus Jakarta Sans

## Estructura

```
landing-workshop/
├── index.html
├── 404.html
├── css/
│   └── styles.css
├── js/
│   └── main.js
├── img/            (vacía — espacio reservado para imágenes)
└── README.md
```

## Cómo abrir

1. Cloná o descargá este repositorio.
2. Abrí `index.html` en tu navegador.
3. También podés publicarlo en **GitHub Pages** apuntando a la rama principal.

## Notas

- No hay backend ni procesamiento de pagos. El checkout y el contador regresivo son de demostración.
- La validación de formularios funciona con JavaScript vanilla.
- Las imágenes están reservadas con placeholders para reemplazar luego.
